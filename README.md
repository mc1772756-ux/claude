# Diário do Pet

App web (pt-BR, mobile-first) para acompanhar a saúde de cães e gatos. Arquivos: `index.html`, `style.css`, `app.js` e `icones.js` (ícones de raças em SVG). Abra `index.html` no navegador; os dados ficam no `localStorage`.

- [x] Vários pets (cão/gato)
- [x] Registro de peso com gráfico
- [x] Ração: marca, horários do alimentador e total de gramas por dia
- [x] Idade (data de nascimento ou aproximada)
- [x] Último banho
- [x] Vacinas, vermífugo e antipulgas com avisos (15 dias antes e atrasadas)
- [x] Doenças e remédios em uso
- [x] Riscos personalizados por raça, idade e ECC: primeiros sinais, prevenção, cuidados até o veterinário e fontes
- [x] Calculadora ECC: peso ideal, meta calórica e gramas de ração (WSAVA)
- [x] Lembrete na agenda: arquivo .ics (agenda nativa do celular) e link do Google Agenda
- [x] Foto do pet ou ícone de raça (18 cães, 10 gatos, desenhos próprios em SVG)
- [x] Remédios: estoque, aviso de fim e lembrete diário na agenda
- [x] Estoque de ração: previsão de quando acaba
- [x] Diário: sintomas (com foto), consultas e exames, gastos por mês e categoria
- [x] Guia de raças: Yorkshire Terrier
- [ ] Exportar/importar backup (incluindo as fotos do IndexedDB)
